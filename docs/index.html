How much quota is left? Look down.

One number per provider, in the status bar, all the time. Codex, Anthropic and OpenCode Go, each with a thin meter that turns amber and then red before you hit the wall.

01What is different here

Compared with upstream v0.3.1, which this repo is merged onto.

Three providers, always remaining

Codex, Anthropic and OpenCode Go only. No Used mode and no eye toggles, so the bar never changes shape on you.

One honest number

Weekly left times session left. A full 5-hour window does not hide an empty week.

Countdown at zero

When something hits 0% the bar adds the time until it resets, as hh:mm.

Compact popover

A Session and Weekly table, one row per Anthropic account. A silent account counts as 0% instead of vanishing.

Codex stays visible

When every Codex login is rate limited, the card stays at 0% with the reset time from Hermes' credential pool.

Multi-account Anthropic

Every Hermes OAuth login is queried, with Opus, Sonnet and credit rows when Anthropic reports them.

bar = session_left x weekly_left / 100 (Anthropic: mean over accounts; OpenCode: 0% if monthly is spent)

02Install

Windows, Hermes Desktop. About two minutes.

  1. Python half, as upstream says. Clone the repo into $HERMES_HOME/plugins/provider-usage/, then run hermes plugins enable provider-usage.
  2. Desktop half. Copy desktop/plugin.js to %LOCALAPPDATA%\hermes\desktop-plugins\provider-usage\plugin.js.
  3. Reload. Press Ctrl+K in Hermes Desktop and pick Reload desktop plugins.

03Limits, plainly

So nothing surprises you.

  • Only Codex, Anthropic and OpenCode Go are drawn. The backend reads more providers; this widget does not show them.
  • Remaining capacity only. No Used mode.
  • No desktop notifications and no burn-rate projections in this layout.
  • Anthropic numbers come from an unofficial usage endpoint, so that card can go blank if Anthropic changes it.
  • Built and checked on Windows. macOS and Linux were not tried.
  • Keys are read from Hermes or the provider CLI at runtime. None are stored in this repo.
